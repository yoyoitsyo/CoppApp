# CoopTD Wall Assistant (starter Android project)

This is a native Android starter project with a floating overlay timer, editable reminder lines, sound/vibration settings, pause/resume and manual wave correction.

## Build APK from an Android phone
1. Create a new **public or private** GitHub repository named `CoopTD-Wall-Assistant`.
2. Upload the contents of this folder to the repository root (not the containing folder itself). Make sure `.github/workflows/build-apk.yml` is included.
3. Open the repository's **Actions** tab. Select **Build Android APK** and tap **Run workflow** (or push to `main` to trigger a build).
4. When the run finishes successfully, open it and download the artifact named `CoopTD-Wall-Assistant-debug`.
5. Extract the artifact ZIP and install `app-debug.apk`. Android may ask you to allow installs from your browser or file manager.
6. Open the app, set seconds per wave, edit reminder lines if desired, save, then tap **Start Floating Timer**. Allow **Display over other apps**. Return to CoopTD.

## Reminder format
One reminder per line: `wave, unit name, action`

Defaults:
- `72, Blue Dragon, LIB`
- `76, Ivy Whisper, PLACE`
- `85, Witch Doctor, PLACE + SSS cooldown gem`

## Important limitations
- Wave progression is estimated from elapsed time and the configured seconds-per-wave value; it does **not** read CoopTD's actual wave counter. Calibrate the interval for your mode and use +/- to correct drift.
- This is an unsigned-by-you debug build, signed with the standard debug key generated by the build environment. It is suitable for personal testing, not Play Store publishing.
- Android versions and device manufacturers may restrict overlays or background services. Keep the app's notification enabled while running.
- This starter is not yet field-tested on your phone. If the cloud build reports an error, share the Actions log and I can help fix it.
